# Nto Uduak's Villa — Quiet Luxury in Uyo

Private short-let villa landing page for Osongama Estate, Uyo, Akwa Ibom State.

## Overview
A calm, premium single-page site for a 3-bedroom self-compound villa — built for families, executives, and weekend escapes in Uyo.

**Brand Name:** Nto Uduak's Villa — "small but precious"
**Location:** Osongama Estate, Uyo, Akwa Ibom
**Contact:** 09069272637

## Tech Stack
- HTML5 — Semantic sections
- CSS3 — Flexbox + Grid, CSS variables, backdrop-filter
- Remix Icons 4.2.0 CDN — No emojis
- No JavaScript

## Pages & Sections
1.  **Navbar (Fixed):** Logo + 3 links (Villas #rooms, About #about, Uyo #contact) + Book Stay CTA
2.  **Hero:** Headline "Quiet luxury, right in Uyo", subheadline, 3 badges (Osongama, 4.9 Rated, Private), 2 CTAs (WhatsApp + See Villas), feature card (3-bed villa, power, WiFi)
3.  **Villas / Rooms (#rooms):** 6 feature cards — Entire Villa, Light Always On, Kitchen Ready, Work & Stream, Secure Estate, Self Check-in
4.  **About (#about):** Story + location benefits (8 mins Tropicana, 10 mins Ibom Plaza, 15 mins Airport) + estate info box
5.  **Footer (#contact):** Phone, email, Instagram, WhatsApp, address, copyright

## Features
- Fixed navbar with blur background
- Responsive at 860px — hero stacks, 3-col features → 1-col, about stacks
- Color system: #FAF8F5 cream bg, #2E6B4A green accent, #C8A96A gold, #142117 dark
- Typography: Arial, 36-52px headings, 12-16px body
- Icons for everything (home, wifi, security, map-pin)
